# Secpar branding

The letterforms are sourced from the outlined wordmark embedded in https://parsec.app/ (retrieved 2026-11-04), matching the supplied reference. The full original font family has not been verified. Website CSS declares Rubik, Barlow, Fira Mono and Inter; those are not treated as identification of the logo typeface.

SECPAR rearranges the original six letterforms, with adjusted kerning. The symbol is a rounded triangle on the same diagonal plane as the reference. Each side uses a 50-unit stroke, avoiding separately drawn inner/outer triangles and uneven band widths. The base follows slope 122/199; the rear layer uses the reference’s (36, -20) offset. Nominal combined stroke bounds remain 285 × 441 units. Its colours are RGB complements of the reference: pink #F50049 becomes mint #0AFFB6; blue #26ABFF becomes orange #D95400. Mint is in front and orange behind. The companion apps remain independently named Secpar.

SecparWordmark.otf is a six-letter logo font assembled from these outlines, mapping S/E/C/P/A/R and lowercase equivalents. It is not a full alphabet or the original Parsec font file. Use the SVG wordmark for the exact final spacing. Interface body text remains the platform font.

Colours: mint #0AFFB6, orange #D95400, near-white #F9FAFC, charcoal #15161A.

Desktop application icons use only the approved triangle on transparency. Android
adaptive icons use a black background and a 0.56-scale foreground, leaving safe
space inside circular and rounded-square masks. Legacy Android icons use a black
rounded tile. Regenerate native PNG/ICO resources with generate-icons.py after
installing the host Node dependencies and Python Pillow. The triangle geometry is unchanged.
