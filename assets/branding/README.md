# Secpar branding

The letterforms are sourced from the outlined wordmark embedded in https://parsec.app/ (retrieved 2026-11-04), matching the supplied reference. The full original font family has not been verified. Website CSS declares Rubik, Barlow, Fira Mono and Inter; those are not treated as identification of the logo typeface.

SECPAR rearranges the original six letterforms, with adjusted kerning. The symbol is a new open S-shaped ribbon, rather than the closed Parsec loop. Its diagonal runs in the opposite direction and the layer colours are swapped: cyan in front, pink behind. The companion apps remain independently named Secpar.

SecparWordmark.otf is a six-letter logo font assembled from these outlines, mapping S/E/C/P/A/R and lowercase equivalents. It is not a full alphabet or the original Parsec font file. Use the SVG wordmark for the exact final spacing. Interface body text remains the platform font.

Colours: cyan #26ABFF, pink #F50049, near-white #F9FAFC, charcoal #15161A.
